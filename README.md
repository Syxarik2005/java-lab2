# Лабораторная работа №2: Вычислитель выражений

## Описание проекта

Данный проект представляет собой консольный калькулятор, способный разбирать и вычислять математические выражения, записанные в виде строки. Проект реализован на языке Java с использованием Maven для сборки и JUnit 5 для тестирования.

В основе алгоритма лежит **метод сортировочной станции** (Shunting-yard algorithm) для преобразования инфиксной нотации в Обратную Польскую Нотацию (ОПН), с последующим её вычислением.

## Основные возможности

*   **Операторы:** Поддерживаются базовые арифметические операторы: `+`, `-`, `*`, `/`, а также возведение в степень `^`.
*   **Приоритет операций:** Корректно соблюдается порядок выполнения операций (умножение и деление выполняются раньше сложения и вычитания).
*   **Скобки:** Поддерживаются вложенные скобки для изменения порядка вычислений.
*   **Переменные:** Выражение может содержать переменные (например, `x`, `y`). Программа автоматически найдет их и запросит у пользователя их значения перед вычислением.
*   **Функции:** Поддерживаются встроенные математические функции:
    *   `sqrt(x)` - квадратный корень
    *   `sin(x)`, `cos(x)`, `tan(x)` - тригонометрические функции (аргумент в градусах)
    *   `abs(x)` - модуль числа
*   **Обработка ошибок:** Программа отлавливает некорректные выражения (например, несбалансированные скобки, деление на ноль) и выводит сообщение об ошибке.

## Технологии

*   Java 21
*   Maven - для управления зависимостями и сборкой проекта
*   JUnit 5 - для модульного тестирования

## Как собрать и протестировать проект

Для работы с проектом вам понадобится установленный JDK и Maven.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Syxarik2005/java-lab2.git
    cd java-lab2
    ```

2.  **Сборка проекта:**
    Команда скомпилирует исходный код.
    ```bash
    mvn compile
    ```

3.  **Запуск тестов:**
    Эта команда запустит все Unit-тесты, которые доказывают корректность работы всех компонентов калькулятора.
    ```bash
    mvn test
    ```
